1. What is C++?

C++ is a general-purpose programming language developed by Bjarne Stroustrup.

It is an extension of C and supports multiple programming paradigms:

Procedural programming

Object-Oriented Programming (OOP)

Generic programming

Low-level/system programming


For DSA, the most important C++ concepts are:

> Variables → Conditions → Loops → Functions → Arrays → Strings → Pointers → References → Structures → Classes → STL → DSA

30. Traversing an Array

int arr[] = {10, 20, 30, 40, 50};

int n = sizeof(arr) / sizeof(arr[0]);

for(int i = 0; i < n; i++)
{
    cout << arr[i] << " ";
}

Important formula

sizeof(arr) / sizeof(arr[0])

gives the number of elements when arr is an actual array in that scope.

Example:

sizeof(arr) = total bytes occupied
sizeof(arr[0]) = bytes occupied by one element

Therefore:

total bytes / bytes per element
= number of elements

69. Recursion

A function calling itself is called recursion.

Example:

void print(int n)
{
    if(n == 0)
        return;

    cout << n << " ";

    print(n - 1);
}

Calling:

print(5);

Output:

5 4 3 2 1

Every recursion needs:

1. Base case


2. Recursive call



Without a proper base case, recursion can continue indefinitely and cause stack overflow.
